# Neo4j State Store for Kafka Streams

This repository contains a proof of concept for integrating Neo4j as a state store within Kafka Streams applications. The primary goal of this project is to explore how we can leverage the graph capabilities of Neo4j to enhance Kafka Streams processing.

## Accompanying Lucene Repository

In conjunction with this project, there is an accompanying Lucene repository that provides additional functionality and optimization for handling text search capabilities within the state store. It showcases how to implement complex queries efficiently.
